# 🏠 House of 49

## 🎮 Game Overview

**House of 49** is a 3D mystery exploration game developed using Unity. The player explores a mysterious house and searches for a hidden key before time runs out.

The game focuses on exploration, player interaction, and finding the key.

## 📖 Story

The player enters a mysterious house called House of 49. Inside the house, a hidden key is waiting to be discovered.

The player must explore the environment and find the key before time runs out.

## 🎯 Game Objectives

- Explore the mysterious house.
- Search for the hidden key.
- Interact with objects in the environment.
- Find the key before the countdown timer reaches zero.

## 🕹️ Gameplay

1. Click **Play** to start the game.
2. Explore the mysterious house.
3. Search different areas of the house.
4. Find the hidden key.
5. Complete the objective before time runs out.

## 🎮 Controls

| Key | Action |
|---|---|
| W | Move Forward |
| A | Move Left |
| S | Move Backward |
| D | Move Right |
| Mouse | Look Around |
| E | Interact / Pick Up Key |
